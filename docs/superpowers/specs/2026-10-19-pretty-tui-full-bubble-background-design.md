# pretty-tui 灰底覆盖完整气泡

## 需求变化

用户反馈上一版灰底面积偏小，要求与蓝色边框区域一样大、稍深，并呈圆角。此方案取代上一版「边框透明、只填正文内部」的范围设计。

## 实现

- 本地源码仍位于 /Users/jiezhou/Desktop/公司其他/pi-pretty-tui。
- 明亮主题 #f3f3f3 改为 #e8e8e8，暗色主题 #282828 改为 #303030。
- 正文行对整个宽度（含左右竖边框）着色，上下边框的横线也着色。
- 四角继续使用蓝色 ╭╮╰╯，其所在单元格不填底色，借透明角格保留圆角轮廓。字符终端无法像 CSS 一样对单元格背景作真正的亚像素圆角裁剪。
- 所有气泡外侧留白保持终端默认背景，宽度、右对齐、复制和鼠标区域不变。

## 验证

修改背景范围的测试，检查顶底横线、正文边框均有灰底，圆角单元格与气泡外侧不染色；运行 npm test 与扩展加载检查。

## 生效

完成后 /restart 换进程，确保旧渲染原型补丁彻底移除；灰度观感由用户确认。
