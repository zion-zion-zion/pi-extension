# pretty-tui 最终方案：只填框内

用户确认：只填框内，边框保持透明。本方案取代此前 full-bubble-background 的边框着色方案。

- 保留较深灰色：亮色 #e8e8e8，暗色 #303030。
- 上下圆角/横线整行不填底色；正文左右竖线的字符格也不填底色。
- 仅对左右竖线之间的正文、内部补齐空格着色；正文行结束前清除背景，再画右边框。
- 不宣称真实圆角灰底。圆角仅来自原蓝框字符，框内灰底与边框之间有字符格留白。
- 本地实现：/Users/jiezhou/Desktop/公司其他/pi-pretty-tui。
- 验证：回归测试断言顶底边框无背景，正文背景在左右竖线之间起止，并运行 npm test 与加载检查。
- 生效：/restart 清理原型补丁中的旧模块。
