# pretty-tui Kitty 圆角气泡集成

## 已验证

用户在 Herdr 0.9.0 + Ghostty 中确认 PNG 圆角显示、负 z 原生文字叠加、简单终端滚动均成功。现在授权接入 Pi。

## 架构

- 只改本地 /Users/jiezhou/Desktop/公司其他/pi-pretty-tui，不改 Pi/Herdr 安装源码。
- fullscreen + Kitty + Herdr 使用图像圆角背景，去掉字符蓝框；其他环境保留透明蓝框与框内灰底。
- 文字渲染仍是纯文本，宽度、换行、点击复制与命中区域不变。为各行附加零宽布局标记，最终发送终端前剥离，不往模型消息/会话内容写标记。
- 在 TuiAltScreen.doRender 外包裹同步的最终写出：读取最终 previousScreen 定位可见行，按真实截取行生成圆角背景片段。保留消息原始高度及行号，顶部被裁掉时不凭空画新圆角。窗口变化重新计算尺寸。
- 背景使用 PNG RGBA 与 Kitty z=-1073741825（低于文字及非默认选择背景），保存/恢复光标，只删除自己分配的图片。主题/尺寸/可见范围改变释放不再使用的资源，缓存有上限。识别 Pi 全局清图后重新上传。
- overlay 打开时暂不绘制背景，防止覆盖弹窗。文本选择/搜索不受 isImageLine 特殊分支影响。
- PNG 使用 Node 内置 zlib 编码，无 Python/额外运行时依赖；超大消息只生成可见片段，限制内存。

## 测试

PNG alpha/灰度、消息裁剪与行位置、缩放/换主题、图片清理、原生清图重传、文字输出和选择保留、补丁关闭恢复；运行上游回归与类型检查，加载检查。实际 Pi UI 仍需用户重启后确认。

## 生效与回退

/restart 清除旧原型/闭包。禁用 pretty-tui 后恢复原渲染并清理本扩展图片；非图像模式保持旧的框内灰底方案。
