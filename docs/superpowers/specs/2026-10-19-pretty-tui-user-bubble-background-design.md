# pretty-tui 用户气泡浅灰底色

## 需求

保留右对齐、蓝色主题边框与现有排版，在用户消息气泡内部加入很浅的灰色背景；外侧留白、助手回复不变。

## 实现与维护

- 从上游 v0.2.9（57ea85a36a35003ba7fed90b611a4ddf8154205e）克隆到 /Users/jiezhou/Desktop/公司其他/pi-pretty-tui，分支 local/user-bubble-gray。
- 修改该本地源码并替换 settings.json 中 npm:pi-pretty-tui@0.2.9 为本地路径，不直接修改 npm 缓存，不双加载。
- 仅对用户气泡正文及内部补齐空格着色；边框和气泡外侧不着色。
- 明亮主题使用 #f3f3f3，暗色主题使用 #282828，避免暗色主题下浅底导致低对比。保留 Markdown 前景与链接，移除正文原有背景，遇到 ANSI reset 时恢复气泡背景，行末清除背景防止串色。
- 保持宽度计算、窄屏降级、复制及鼠标命中规则不变。

## 验证与生效

运行上游类型检查和回归测试，新增灰底边界、ANSI reset、多行/中文、主题和窄屏测试。通过 Pi loader 检查本地加载无错误，检查只存在一个 pretty-tui 来源。
完成后使用 /restart 换进程，避免原型补丁仍持有旧模块；用户确认实际灰度观感。
